# Контракт игровых автоматов

Интерфейс [`GameMachine`](../api/src/main/java/org/example/casino/GameMachine.java) берётся из ветки `main`. Каталог читает метаданные, а контроллер передаёт выбранному автомату управление его окном.

| Метод | Соглашение |
| --- | --- |
| `String id()` | Стабильный уникальный идентификатор вида `фамилия.игра`. Пустое значение и повтор считаются ошибками регистрации. |
| `String title()` | Непустое название для каталога и заголовка окна. При совпадении названий игры различаются по фамилии автора. |
| `void open()` | Вызывается из потока JavaFX. Открывает окно и возвращает управление после закрытия. Ошибка подготовки окна передаётся как исключение с причиной. |

`FxGameMachine` создаёт модальное окно и вызывает `prepare(Stage)` у адаптера. Адаптер загружает вид исходного автомата и устанавливает его сцену. Базовый класс добавляет кнопку возврата и закрывает окно при ошибке подготовки. Контроллер зала показывает ошибку рядом с каталогом.

## Общий баланс

`BalanceManager` находится в модуле `api` и хранит единое количество условных монет на время работы приложения. Игры используют его через методы `addCoins`, `spendCoins` и `getCoins`. Поэтому пополнение, ставка и выигрыш, сделанные в одном автомате, сохраняются после возврата в каталог и открытия другого автомата.

Баланс не допускает отрицательных значений: при недостатке монет `spendCoins` возвращает `false`. Экран игрового зала подписывается на изменение счёта и сразу обновляет его в шапке. У каждого игрового модуля остаются собственные правила розыгрыша и счётчик его попыток.

## Подключение нового автомата

1. Добавьте Maven-модуль в `games/`, разместите в нём исходники и ресурсы игры. Возьмите за пример существующий модуль с тем же способом построения интерфейса.
2. Добавьте адаптер с уникальным `id()` и названием. Для JavaFX унаследуйте `FxGameMachine` и реализуйте `prepare(Stage)`.
3. В `module-info.java` зарегистрируйте поставщика через `provides org.example.casino.GameMachine with ...`. Для FXML откройте пакет контроллера модулю `javafx.fxml`.
4. Добавьте модуль в `games/pom.xml` и его зависимость со scope `runtime` в `hall/pom.xml`. `ServiceLoader` обнаружит его при запуске.
5. Выполните сборку и проверку открытия игры, возврата и доступности остальных автоматов.
