# Работа с Git

Общий репозиторий команды — [PROCuuuba/Casino](https://github.com/PROCuuuba/Casino). Исходные ветки авторов и соответствие игр перечислены в [контракте](integration-contract.md).

1. Ответвляйтесь от актуальной `main` для согласованных изменений. Для новой игры используйте имя ветки `game/<фамилия>`, для изменений зала — `integration/<задача>`.
2. Автор автомата отвечает за свой модуль и сценарий его проверки. Интегратор отвечает за подключение модуля, каталог и совместную сборку. Изменения контракта согласуются участниками команды.
3. В Pull Request опишите исходную игру, изменения адаптера и результаты проверки. Приложите команду запуска и шаги для сценария «открыть → сыграть → вернуться».
4. Другой участник проверяет код и запуск до слияния. Проверьте каталог, запуск новой игры и возврат из неё, затем повторите сценарий на одном из подключённых автоматов.
5. После согласования интегратор объединяет изменения в `main`. Существенные изменения интерфейса фиксируйте в контракте и журнале изменений.
