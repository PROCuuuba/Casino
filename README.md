# Casino

Casino — настольное приложение на JavaFX, которое объединяет семь независимо разработанных игровых автоматов в одном каталоге. У каждого автомата свой интерфейс, правила и баланс условных монет.

Проект выполнен в рамках [«Интеграции 1» учебного задания «Вегас»](https://github.com/olgmina/SWEngineering-technics.github.io/blob/gh-pages/Labs/prTask_GameHall.md#интеграция-1-объединение-игровых-автоматов).

## Быстрый запуск

Нужны Git, JDK 21 или новее и графическая сессия. Maven Wrapper скачает Maven и зависимости при первом запуске.

```shell
git clone https://github.com/PROCuuuba/Casino.git
cd Casino
./mvnw -Pplay verify
```

В Windows из папки `Casino` выполните `.\mvnw.cmd -Pplay verify`.

В IntelliJ IDEA откройте корневой `pom.xml` как Maven-проект. Выберите JDK 21 или новее для проекта и Maven Runner, затем запустите `-Pplay verify` в конфигурации Maven с рабочей папкой `Casino`.

## Игровой каталог

Выберите игру и нажмите **Открыть автомат**. В окне игры внесите монету, начните раунд и сделайте ход. Кнопка **В каталог** или закрытие окна игры возвращает к выбору автомата.

| Автомат | Исходная ветка |
| --- | --- |
| Три мешочка — Баркалов | `Barkalov` |
| Ludka — Черных | `Chernixa` |
| Пиксельный автомат — Коренцов | `Korentsov` |
| Три мешочка — Ларин | `Larin` |
| Три барабана — Могилевцев | `Mogilevtsev` |
| Казик — Путилин | `Putilin` |
| Мешочки — Варганов | `Varganov` |

Если окно автомата не открылось, каталог показывает причину ошибки и позволяет выбрать другую игру.

## Структура проекта

| Каталог | Содержимое |
| --- | --- |
| `api/` | Интерфейс `GameMachine` и общий адаптер для окон JavaFX |
| `hall/` | Главное окно, контроллер каталога и интеграционные тесты |
| `games/` | Семь Maven-модулей с исходными играми, ресурсами и адаптерами |
| `tests/probe/` | Дополнительный автомат для проверки расширяемости каталога и ошибки запуска |
| `docs/` | Контракт, UML и правила командной работы |

Зал обнаруживает игровые модули через `ServiceLoader`. Для подключения новой игры нужны адаптер, регистрация поставщика и зависимость в сборке. Порядок подключения описан в [контракте интеграции](docs/integration-contract.md).

## Проверка

| Команда | Результат |
| --- | --- |
| `./mvnw verify` | Собирает все модули и проверяет состав каталога, уникальность идентификаторов и обнаружение дополнительного модуля |
| `./mvnw -Dcasino.gui.tests=true verify` | Дополнительно проверяет запуск семи игр, завершение раунда, возврат в каталог и отказ запуска |
| `./mvnw -Pplay -Djavafx.args=--list verify` | Выводит список игр из рабочей сборки в терминал |
