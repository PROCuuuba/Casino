# Casino

Casino — настольное приложение на JavaFX, которое объединяет восемь независимо разработанных игровых автоматов в одном каталоге. У каждого автомата свой интерфейс и правила, а монеты игрока хранятся в общем балансе игрового зала.

Проект выполнен в рамках [«Интеграции 1» учебного задания «Вегас»](https://github.com/olgmina/SWEngineering-technics.github.io/blob/gh-pages/Labs/prTask_GameHall.md#интеграция-1-объединение-игровых-автоматов).

## Быстрый запуск

Нужны Git, JDK 21 или новее и графическая сессия. Maven Wrapper скачает Maven и зависимости при первом запуске.

```shell
git clone https://github.com/PROCuuuba/Casino.git
cd Casino
./mvnw -Pplay verify
```

В Windows из папки `Casino` выполните `.\mvnw.cmd -Pplay verify`.

В IntelliJ IDEA откройте корневой `pom.xml` как Maven-проект. Выберите JDK 21 или новее для проекта и Maven Runner, затем запустите `-Pplay verify` в конфигурации Maven с рабочей папкой `Casino`.

## Игровой каталог

Выберите игру и нажмите **Открыть автомат**. В окне игры внесите монету, начните раунд и сделайте ход. В рулетке выберите цвет и сумму ставки, затем нажмите **Крутить** или Enter. Кнопка **В каталог** или закрытие окна игры возвращает к выбору автомата. В шапке показан общий баланс: ставки, внесённые монеты и выигрыши всех автоматов учитываются в одном месте. Кнопка **+ 5 монет** пополняет баланс для начала игры. Музыку в меню можно выключить кнопкой в шапке.

| Автомат | Исходная ветка |
| --- | --- |
| Три мешочка — Баркалов | `Barkalov` |
| Ludka — Черных | `Chernixa` |
| Пиксельный автомат — Коренцов | `Korentsov` |
| Три в ряд — Ларин | `Larin` |
| 5 из 36 | `Mogilevtsev` |
| Рулетка — Путилин | `Putilin` |
| Сундуки — Варганов | `Varganov` |
| Орбита | `test-slot-machine` |

Если окно автомата не открылось, каталог показывает причину ошибки и позволяет выбрать другую игру.

В рулетке девять равных секторов: четыре красных, четыре чёрных и один зелёный. Красный и чёрный дают выплату ×2, зелёный — ×5, включая ставку. Сумму можно ввести с клавиатуры или выбрать кнопками **10**, **25**, **50**, **100**. Правила и устройство модуля описаны в [документации рулетки](games/putilin/docs/integration.md).

Полная проверка сборки и окон всех игр из корня репозитория:

```powershell
.\mvnw.cmd -B clean verify '-Dcasino.gui.tests=true'
```

## Структура проекта

| Каталог | Содержимое |
| --- | --- |
| `api/` | Интерфейс `GameMachine`, общий адаптер окон JavaFX и `BalanceManager` |
| `hall/` | Главное окно, каталог, фоновая музыка и интеграционные тесты |
| `games/` | Maven-модули с исходными играми, ресурсами и адаптерами |
| `tests/probe/` | Дополнительный автомат для проверки расширяемости каталога и ошибки запуска |
| `docs/` | Контракт, UML и правила командной работы |
