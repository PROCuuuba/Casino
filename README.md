# Casino

Учебный игровой зал для этапа [«Интеграция 1»](https://github.com/olgmina/SWEngineering-technics.github.io/blob/gh-pages/Labs/prTask_GameHall.md). Каталог объединяет семь индивидуальных автоматов.

## Запуск

Нужен JDK 21 или новее. В IntelliJ IDEA откройте корневой `pom.xml` как Maven-проект и укажите этот JDK в настройках проекта и Maven Runner. Из корня проекта запустите:

```shell
./mvnw -Pplay verify
```

В Windows используйте `mvnw.cmd -Pplay verify`. Эту же команду можно выполнить через Maven Run Configuration в IntelliJ IDEA, указав `-Pplay verify` в поле запуска Maven.

Выберите автомат, нажмите «Открыть автомат», внесите игровую монету и начните раунд. Кнопка «В каталог» и закрытие окна игры возвращают в тот же каталог.

| Исходная ветка | Автомат в каталоге |
| --- | --- |
| `Barkalov` | Три мешочка — Баркалов |
| `Chernixa` | Ludka — Черных |
| `Korentsov` | Пиксельный автомат — Коренцов |
| `Larin` | Три мешочка — Ларин |
| `Mogilevtsev` | Три барабана — Могилевцев |
| `Putilin` | Казик — Путилин |
| `Varganov` | Мешочки — Варганов |

## Проверка

- `./mvnw verify` собирает проект и проверяет обнаружение игр, уникальность идентификаторов и подключение дополнительного модуля.
- `./mvnw -Dcasino.gui.tests=true verify` дополнительно проверяет окна JavaFX, начало игры во всех семи автоматах, завершение раунда, возврат и обработку ошибки запуска. Нужна графическая сессия.
- `./mvnw -Pplay -Djavafx.args=--list verify` печатает каталог из рабочей сборки.
