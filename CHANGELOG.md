# Журнал изменений

## Общий баланс и интерфейс зала

- Добавлен единый счёт монет для всех игровых модулей.
- Каталог переделан в витрину с карточками автоматов.
- Добавлено пополнение общего баланса и фоновая музыка с выключателем.
- Добавлен ресурс музыкального сопровождения меню.

## Интеграция 1

- Добавлен каталог JavaFX, который открывает семь индивидуальных игр через контракт `GameMachine` из `main`.
- Для игровых окон добавлен возврат в каталог. При ошибке запуска каталог показывает сообщение и остаётся доступным.
- Игры собраны в Maven-модули со своими ресурсами и внутренним учётом условных монет.
- Добавлены документация контракта, UML и проверка сценариев приёмки.
